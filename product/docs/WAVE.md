# MemoGuard Wave application

As of 2026-10-08, all four MemoGuard repositories are public and MIT licensed. They have CONTRIBUTING and SECURITY guidance. These repositories have **not yet been applied to or approved by** the Stellar Wave Program.

The organization owner must sign in at [Drips Wave](https://www.drips.network/wave/stellar), open **Maintainers → Orgs and Repos**, install the [Drips Wave GitHub App](https://github.com/apps/drips-wave) on `Memoguard8876`, sync the four public repositories, and apply each relevant repository to the Stellar Wave Program. Program organizers decide approval. [Drips' maintainer instructions](https://docs.drips.network/wave/maintainers/participating-in-a-wave/) explain the process and appeal rules.

The following scoped issues are ready for contributors. **Add a Wave issue only after its repository is approved**, then set its complexity in the Drips app or apply the `Stellar Wave` label. The complexity suggestion is in each issue body.

During a Wave, maintainers must review applications, assign contributors, review pull requests, and merge accepted work promptly. A real-user pilot and rule tuning remain necessary before recommending MemoGuard as a mandatory CI gate.
